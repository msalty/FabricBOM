What is FortiClient?

FortiClient is the software agent Fortinet installs on laptops and desktops. At its base tier it gives users secure remote access, either through a virtual private network (VPN) or through Zero Trust Network Access (ZTNA), which checks each device's security posture before letting it reach a specific application behind a FortiGate. Higher tiers add endpoint protection against malware and ransomware, or hand day-to-day operation to Fortinet's own team.

Every endpoint is managed from the Endpoint Management Server (EMS). The customer can run EMS on their own server or use FortiClient Cloud, where Fortinet hosts it. Licenses are sold per device in packs of 25, 500, 2,000, and 10,000, and each pack includes FortiCare Premium support.

Where to start: choose Cloud or On-premise under Deployment & solution first. Licenses can't be converted between the two later. Then pick a solution tier and enter the number of endpoints.

Deployment & solution
Cloud or on-premise? FortiClient Cloud is an EMS instance that Fortinet hosts, so there is no server to build or patch. It manages up to 250,000 endpoints and doesn't need a FortiCloud Premium subscription. On-premise EMS runs on the customer's Linux server (EMS 7.4) or Windows Server (EMS 7.2 and earlier), in their datacenter or public cloud. Choose on-premise for air-gapped networks.
No cross-upgrades: a cloud license can't be upgraded to on-premise, or the reverse. Moving between them means buying new SKUs for the new EMS instance. The Best Practice Service team can help with the migration.
Sets which license family (EMS05 cloud or EMS04 on-premise) is ordered.
Standalone VPN doesn't use EMS, so the deployment choice doesn't apply. Users are managed through FortiIdentity Cloud.
Which tier?
  • VPN/ZTNA covers secure remote access plus basic hygiene: vulnerability scanning, web filtering and CASB.
  • EPP/ATP adds full endpoint protection: AI-based antivirus, sandboxing, ransomware protection and automatic quarantine. It includes everything in VPN/ZTNA.
  • Managed is EPP/ATP plus Fortinet experts who onboard, provision and monitor the endpoints. It is cloud-only and includes Best Practice Service consultation.
  • Standalone VPN is per-user IPsec VPN for small sites that don't want EMS. The minimum order is 50 users.

Ordering process notes
What's the simplest way to order?
Buy per-device packs for a 1 to 5-year term. The Example BOMs tab walks through a new order, adding endpoints, renewing and upgrading.
How do I move a customer from one FortiClient tier to another?
Use the co-term tool, which upgrades the existing licenses through the end of their current term. Upgrades only work within cloud or within on-premise, never across them. The upgrade matrix is on the Example BOMs tab.
The customer has older EMS01 or EMS03 licenses. Can they upgrade to EMS04 or EMS05?
No. The feature sets changed, so there's no direct upgrade path. Quote new EMS04 or EMS05 SKUs at renewal. If they're on-premise with the older SKUs, renewal is a good time to consider moving to FortiClient Cloud.
Where did the FortiSASE option go?
It's still available, and FortiClient licenses can be upgraded to FortiSASE. The SKUs are covered in the FortiSASE ordering guide.
Is there certification for the customer's administrators?
Yes. The FCP FortiClient EMS Administrator course covers provisioning endpoints, Security Fabric integration, and configuring the ZTNA agent and endpoint security features. Training SKUs and delivery options are listed on training.fortinet.com.

Renewals and upgrades (co-term tool)

These steps use renewal SKUs that the co-term tool creates for each quote. They aren't on the price list, so there's no part number to add from this page. Build them in the co-term tool.

Renew all endpoints. Say a customer bought one 500-pack and later added two 25-packs, for 550 endpoints. At the first renewal, run all three packs through the co-term tool together. It renews each pack at its own band (two 25-pack band lines and one 500-pack band line) and moves every contract to the same expiry date.
Upgrade all endpoints. To move those 550 VPN/ZTNA endpoints to EPP/ATP, use the co-term tool to upgrade every pack through the end of the current term. After that, renew normally at the EPP/ATP tier.
Upgrade limits: no upgrades between cloud and on-premise. Chromebook licenses can't be upgraded to or from any other tier. EMS01 and EMS03 licenses can't be upgraded to EMS04 or EMS05.

Sizing and architecture notes
Forensics needs log capacity. Forensics bundles forward FortiClient logs to SOCaaS through FortiAnalyzer, which isn't included. For FortiAnalyzer Cloud, add log storage. For on-premise FortiAnalyzer, confirm it has room for the extra endpoint logs.
Capacity: one FortiClient Cloud instance manages up to 250,000 endpoints. On-premise EMS can run on Linux (7.4) or Windows Server (7.2 and earlier), in the customer's datacenter or in a public cloud.
